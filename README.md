# 🕵️ Детектив

**Дело каждый раз новое: генерируются жертва, место, шестеро подозреваемых и улики.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/detective/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Процедурная генерация с гарантией: убийца — единственный, кто подходит под все улики
- Ни одна улика не указывает на убийцу в одиночку
- 6 действий: осмотреть место преступления или допросить подозреваемого
- Вычёркивание подозреваемых и статистика раскрытых дел

## Стек

JavaScript, генерация логических головоломок. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/detective.git
cd detective
python3 -m http.server 8000
```
